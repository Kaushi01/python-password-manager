# Personal Password Manager

A Python-based command-line password manager that allows users to:

- Save website names and passwords.
- View saved passwords.
- Generate random passwords.
- Store password records locally using a text file.

## Technologies Used
- Python
- Random module
- String module
- File Handling
- Dictionaries
- Exception Handling
- Loops and Conditional Statements

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python password_manager.py
```

## Features
- Password generation
- Password storage
- Password retrieval
- Menu-driven interface

**Note:** This is a beginner Python project for learning file handling and basic password management. It stores passwords in plaintext, so do not use it for storing real credentials.
